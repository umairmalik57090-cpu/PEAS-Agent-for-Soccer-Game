## 🏟️ AI Soccer Agent Using PEAS Framework

### 📌 Project Description

This project demonstrates the design of an **Artificial Intelligence agent for a Soccer Game** using the **PEAS (Performance Measure, Environment, Actuators, Sensors) framework**. The goal of this project is to explain how intelligent agents perceive their environment and make decisions based on sensed information.

The agent follows basic AI principles by sensing the game environment (such as ball and opponent positions) and performing appropriate actions like moving, passing, or shooting. This project is developed as part of an **Artificial Intelligence course assignment**.

---

### 🎯 Objectives of the Project

* To understand the concept of **intelligent agents**
* To apply the **PEAS framework** in a real-world scenario
* To design a simple **rule-based soccer agent**
* To implement agent behavior using **Python**
* To demonstrate AI decision-making with clear output

---

### 🧠 PEAS Model for Soccer Agent

* **Performance Measure:**
  Scoring goals, maintaining possession, preventing opponent goals, and making correct decisions.

* **Environment:**
  Soccer field, ball, teammates, opponents, goalposts, and referee.

* **Actuators:**
  Move, kick, pass, and shoot.

* **Sensors:**
  Ball position, opponent position, teammate position, and game state.
